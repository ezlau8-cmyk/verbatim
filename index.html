Verbatim for Google Docs

v1.0.0 GPL-3.0 Paperless-debate toolkit for Google Docs. ~90 seconds to install.

What this is

A port of Verbatim (the standard Word-based paperless-debate toolkit) to Google Docs as a Google Apps Script add-on. After you install it once, the Verbatim for Google Docs menu appears in every Google Doc you open. Press F3 to condense, Opt+F3 to shrink, F11 to highlight — same workflow as Word Verbatim.

Install — five pastes, ~60 seconds

⚠️ Sign in to your SCHOOL account first Your school has Apps Script enabled. Your personal account does not. Before you click anything else:
  1. Click your profile picture (top right of any Google page).
  2. Select your school account (e.g. you@school.edu) — NOT your personal Gmail.
  3. Confirm by checking the profile chip again — it should show your school email.
If you're already signed in to your personal account, the OAuth screen will reject the script and you'll see "This app is blocked" or "Access denied". Switch accounts first.
Step 1 — Open Apps Script With your school account active, click below to open a fresh Apps Script project in a new tab.

Step 2 — Paste the five files In the new tab, you'll see an empty script with a `function myFunction() {}` placeholder. Below are five files. For each one:
  1. Click the filename's Copy contents button (in this page).
  2. Switch to the Apps Script tab.
  3. For Code.gs: select all (Cmd+A) in the placeholder, delete, paste.
  4. For the others: click File → New → Script file (or HTML file), type the filename exactly (including the extension — e.g. Sidebar.html), press Enter. Paste the contents you copied.
  5. Save (Cmd+S / Ctrl+S).

Tip: the filename must match exactly — including the .html extension — or Apps Script won't recognize it as an HTML file.

Step 3 — Save the project In the Apps Script tab, just press Cmd+S (or Ctrl+S) to save everything. Done. You don't need to touch Project Settings — all the file's required settings live inside appsscript.json which you already pasted.
Step 4 — Deploy In the Apps Script editor: Deploy → Test deployments → Install. Accept the OAuth consent (it asks for the narrow scope: see below).
Step 5 — Verify Open any Google Doc. You should see Extensions → Verbatim for Google Docs. Click Open Verbatim sidebar. First time in a doc: click Install Styles.

What permissions does this ask for? Only documents.currentonly, script.container.ui, and drive.file — the narrowest set Google allows. The script cannot read other Docs in your Drive, cannot send mail, cannot touch your contacts or calendar. All processing happens inside Google's Apps Script runtime. Your evidence stays in your account.

First-run checklist

Open the sidebarIn any Google Doc, click Extensions → Verbatim for Google Docs → Open Verbatim sidebar.
Install styles (once per doc)In the sidebar, click "Install Styles".
Cut a cardPaste text → F3 (condense) → Opt+F3 (shrink) → select + F11 (highlight) → F4–F7 (Pocket/Hat/Block/Tag).
Send to speechCreate a Google Doc called "Speech". Paste its URL into the sidebar → Bind. Hit ` (backtick) to send cards.

If something goes wrong

  1. "This app is blocked" / "Access denied" / "Apps Script is disabled": You're on the wrong account. Click your profile picture (top right of the Apps Script tab) and switch to your school account. Try Step 1 again.
  2. OAuth consent doesn't show your school account: the Apps Script project opened in your personal Gmail. Close that tab, switch to your school account, click Step 1 again.
  3. Menu doesn't show after install: hard-reload the Doc (Cmd+Shift+R). Wait 30 seconds. Apps Script caches add-on registration.
  4. "Can't find file appsscript.json": you probably created it via File → New but typed a different name. The filename must be exactly appsscript.json (with the dot, in that case) for Apps Script to treat it as the manifest. If you don't see the file in the sidebar, check that it exists at all and the name matches.
  5. Paste button copies nothing: your browser may be blocking clipboard access. Open the file manually at github.com/ezlau8-cmyk/verbatim/tree/master/gdocs/appsscript, copy from there.
  6. "This script has too many OAuth scopes": your school admin may need to approve the scopes. Send IT this list: documents.currentonly, script.container.ui, drive.file.
