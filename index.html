Verbatim for Google Docs

v1.0.0 GPL-3.0 Paperless-debate toolkit for Google Docs. Works on Chromebook, Windows, Mac — anywhere Google Docs runs.

What this is

A port of Verbatim (the standard Word-based paperless-debate toolkit) to Google Docs as a Google Apps Script add-on. You install it once into your own Google account, and the Verbatim for Google Docs menu appears in every Google Doc you open. Press F3 to condense, Opt+F3 to shrink, F11 to highlight — same workflow as Word Verbatim.

Install (≈90 seconds)

  1. Make sure you're signed into your own Google account (not a school-managed account unless Apps Script is allowed there).
  2. Click Start install below. It opens Google Apps Script in a new tab with the Verbatim project pre-loaded.
  3. Click the ⋮ menu in the new tab → Make a copy. The copy is now yours, in your account.
  4. Open any Google Doc. Look for Extensions → Verbatim for Google Docs → Open Verbatim sidebar.
  5. First time in a doc: click Install Styles in the sidebar.

Or open Apps Script directly

The "Start install" button copies the Verbatim source files to your clipboard, then opens Apps Script with a one-shot URL containing the bundle. Apps Script imports them, and you click "Make a copy" to claim the project. If your browser blocks the auto-import, the "Or open Apps Script directly" link above gets you to a fresh project — you'll need to drag the source files in manually (instructions appear after click).

Manual install (10 files to paste)

Click each filename below to copy its contents to your clipboard, then paste into a new file in Apps Script (File → New → Script file).

Do this only if the one-click install above didn't work. The list is in the order you should add them.

After all files are added:

  1. Click Cmd+S (Ctrl+S on Windows) to save. The manifest file MUST be named appsscript.json exactly — Apps Script will reject it otherwise.
  2. Click Deploy → Test deployments → Install.
  3. Open any Google Doc. Extensions → Verbatim for Google Docs.

First-run checklist

Open the sidebarIn any Google Doc, click Extensions → Verbatim for Google Docs → Open Verbatim sidebar.
Install styles (once per doc)In the sidebar, click "Install Styles". The Verbatim paragraph styles (Pocket/Hat/Block/Tag/Cite) are now in the doc.
Cut a cardPaste text. Press F3 (condense). Press Opt+F3 (shrink). Select text + F11 (highlight). Press F4–F7 to mark Pocket/Hat/Block/Tag.
Send to speechCreate a Google Doc called "Speech". Paste its URL into the sidebar's Speech Doc field → Bind. Hit the ` key (backtick) to send cards.

Keyboard shortcuts (Mac)

Show full shortcut list

If F-keys don't fire: System Settings → Keyboard → "Use F1, F2, etc. as standard function keys" → on. After that bare F-keys work without holding Fn.

  • F2 — Paste Text (unformatted)
  • F3 — Condense (with current pilcrow mode)
  • Cmd+Opt+F3 — Condense With Pilcrows
  • Cmd+F3 — Condense No Pilcrows
  • Cmd+Opt+Shift+F3 — Uncondense
  • Opt+F3 — Shrink (8-ball cycling)
  • F4 — Pocket
  • F5 — Hat
  • F6 — Block
  • F7 — Tag
  • F8 — Cite
  • F9 — Underline
  • F10 — Emphasis
  • F11 — Highlight
  • F12 — Clear Formatting
  • ` (backtick) — Send To Speech
  • Opt+` — Send To Speech End
  • Cmd+Opt+↑/↓ — Move Up / Move Down
  • Cmd+Opt+Shift+↓ — Move To Bottom

If something goes wrong

The most common issue is "I don't see the menu". Try:

  1. Hard reload the Doc (Cmd+Shift+R or Ctrl+Shift+R).
  2. Wait 30 seconds — Apps Script caches add-on registration.
  3. Open the script at script.google.com and run any function (e.g. cmdWordCount) — that triggers the OAuth consent.
  4. If your school blocks Apps Script, talk to IT. The scopes we use are minimal (documents.currentonly, script.container.ui, drive.file).
