Verbatim for Google Docs

An open-source, GPL3-0 paperless-debate toolkit ported from the original Word desktop template (ashtarcommunications/verbatim).

Quickstart

1. InstallUse the deployment link your captain shared. Click Install and grant the requested permissions.
2. Open a DocOpen (or create) any Google Doc.
3. Open the sidebarExtensions → Verbatim for Google Docs → Open Verbatim sidebar.
4. Install stylesClick Install Styles in the sidebar. You only need to do this once per doc.
5. Cut a cardPaste text, press F2 or click Paste Text. Use Condense (F3), then Shrink (⌥F3), then highlight (F11) the parts you want to read aloud. Press F4–F7 to mark the surrounding Pocket/Hat/Block/Tag.

Document structure

Verbatim uses four heading levels that map to Google Docs headings:

  • F4 Pocket (Heading 1)
  • F5 Hat (Heading 2)
  • F6 Block (Heading 3)
  • F7 Tag (Heading 4) — the smallest unit, usually one card

Card text is normal text; cites are bold normal-text paragraphs (apply with F8).

Paperless flow

Bind a Speech document from the sidebar (paste its URL). Then Send To Speech (`) sends the current card to the bound speech doc. While inside the speech doc, Mark Card drops a timestamped marker.

Coming from Word Verbatim?

All core actions are 1:1. Some platform differences:

  • Pilcrows (¶) are inserted as plain characters, not as hidden field codes. They look the same and round-trip cleanly.
  • Reading view uses Google Docs' built-in reader mode (no need for a Verbatim toggle).
  • Macros that rely on Word's VBA (OCR, Caselist, Tabroom share, NSIS installer) are not implemented in this version — see the Limitations tab.

Getting help

Run Help → Cheat Sheet for shortcuts. See the Verbatim Help menu and the docs at paperlessdebate.com for workflow guides.
